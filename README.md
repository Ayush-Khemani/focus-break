# Focus / Break

A minimal split-screen Pomodoro timer with a 25-minute focus session and a 5-minute break.

## Features

- 50/50 split-screen desktop layout
- Responsive stacked mobile layout
- Start, pause, and reset controls
- Custom focus and break durations
- Optional auto-start between sessions
- Keyboard shortcuts: `Space` to start/pause, `R` to reset
- No frameworks, dependencies, build tooling, or tracking
- Ready for GitHub Pages

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

## Deploy to GitHub Pages

Because this is a static site, publish the repository root from the `main` branch in GitHub Pages settings.
